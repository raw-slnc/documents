# Documents

This repository collects personal notes and working documents about QGIS plugin
design, forestry workflows, geospatial tools, and practical software
development.

The documents are not official specifications. They are used to clarify design
intent, record ideas, and reflect on how tools can better support real work.

My focus is on modest, reliable tools that respect practical constraints:
Japanese paths and data formats, clear workflows, readable outputs, careful
testing, and responsible use of AI-assisted implementation.
